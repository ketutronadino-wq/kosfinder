| 11 | US04‑AC2 (WhatsApp Tidak Terpasang / Nomor Tidak Valid) | 1. Pada detail kos dengan nomor tidak valid atau di perangkat tanpa WhatsApp, tekan tombol **Hubungi via WhatsApp**. | Ditampilkan snackbar/error yang menyatakan “WhatsApp tidak dapat dibuka”. |  |  |
| 12 | US05‑AC1 (Registrasi) | 1. Buka layar **Register**.<br>2. Isi email & password yang valid.<br>3. Tekan **Daftar**. | Akun Supabase dibuat, pengguna diarahkan ke dashboard “Kos Saya”. |  |  |
| 13 | US05‑AC2 (Login Gagal) | 1. Buka layar **Login**.<br>2. Masukkan kombinasi email/password yang salah.<br>3. Tekan **Masuk**. | Ditampilkan pesan error autentikasi yang jelas (mis. “Email atau password salah”). |  |  |
| 14 | US05‑AC1 (Koneksi Gagal) | 1. Matikan koneksi internet.<br>2. Coba registrasi atau login. | Ditampilkan pesan error jaringan, tidak ada perubahan akun. |  |  |
| 15 | US06‑AC1 (Tambah Kos Berhasil) | 1. Masuk sebagai pemilik.<br>2. Tekan **Tambah Kos** (FAB).<br>3. Isi semua kolom wajib (nama, tipe, area, alamat, harga, WA, fasilitas).<br>4. | 16 | US06‑AC2 (Validasi Form Kosong) | 1. Buka form tambah kos.<br>2. Biarkan kolom wajib (mis. nama atau harga) kosong.<br>3. Tekan **Simpan**. | Form menandai kolom yang kosong dengan pesan error; tidak ada request ke Supabase. |  |  |
| 17 | US06‑AC1 (Koneksi Gagal) | 1. Isi form lengkap.<br>2. Matikan jaringan sebelum menekan **Simpan**. | Ditampilkan pesan error koneksi; data tidak tersimpan. |  |  |
| 18 | US07‑AC1 (Edit/Update Berhasil) | 1. Masuk sebagai pemilik, buka **Kos Saya**, pilih kos miliknya, tekan **Edit**.<br>2. Ubah satu atau beberapa field, mis. harga.<br>3. Tekan **Simpan**. | Perubahan tersimpan di Supabase, langsung terlihat di tampilan publik serta di dashboard. |  |  |
| 19 | US07‑AC2 (Pemilik B Mencoba Edit Kos Pemilik A) | 1. Login sebagai **Pemilik B**.<br>2. | 20 | US07‑AC1 (Koneksi Gagal) | 1. Buka form edit kos milik sendiri.<br>2. Matikan jaringan sebelum menekan **Simpan**. | Ditampilkan pesan error koneksi; perubahan tidak tersimpan. |  |  |
| 21 | US08‑AC1 (Arsipkan Kos) | 1. Pada dashboard “Kos Saya”, pilih sebuah kos aktif.<br>2. Tekan tombol **Arsipkan Kos** dan konfirmasi. | Field `is_active` menjadi `false`; kos tidak muncul di pencarian publik, tetapi terlihat di dashboard dengan label “Diarsipkan”. |  |  |
| 22 | US08‑AC2 (Aktifkan Kembali) | 1. Pada dashboard, pilih kos yang berlabel “Diarsipkan”.<br>2. Tekan **Aktifkan Kembali** dan konfirmasi. | `is_active` berubah menjadi `true`; kos kembali muncul di pencarian publik. |  |  |
| 23 | US08‑AC1 (Koneksi Gagal) | 1. Pilih kos untuk di‑arsipkan.<br>2. Matikan jaringan sebelum menekan **Arsipkan Kos**. | Ditampilkan pesan error jaringan; status kos tidak berubah. |  |  |
| 24 | US01‑AC1 (Koneksi Gagal – Global) | 1. Simulasikan kegagalan server Supabase (mis. endpoint 500).<br>2. Buka aplikasi. | Seluruh UI menampilkan pesan error koneksi dengan tombol **Coba Lagi**; tidak ada crash. |  |  |
| 25 | US06‑AC2 (Validasi Form Kosong – Global) | 1. Pada form tambah atau edit, kosongkan semua kolom wajib.<br>2. Tekan **Simpan**. | Semua kolom wajib menampilkan indikator error; tombol **Simpan** tetap dinon‑aktifkan atau tidak memicu request. |  |  |
| 26 | US04‑AC2 (WhatsApp Tidak Terpasang – Global) | 1. Pada perangkat tanpa aplikasi WhatsApp, buka detail kos dan tekan **Hubungi via WhatsApp**. | Snackbar menampilkan pesan “WhatsApp tidak dapat dibuka”. |  |  |

| 30 | US03‑AC2 (Gambar Rusak – Global) | 1. Pilih kos dengan `image_url` yang mengarah ke URL 404 atau non‑gambar.<br>2. Buka detail. | Placeholder gambar ditampilkan, tidak ada error UI. |  |  |
